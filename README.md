# PetAlerta — Global Solution FIAP

## Sobre o projeto

O PetAlerta é uma proposta de solução CitizenTech que busca conectar tutores, cidadãos, ONGs e protetores independentes para facilitar a localização de animais desaparecidos, o registro de animais encontrados e a mobilização de apoio aos animais em situação de vulnerabilidade.

## Problema identificado

A divulgação de animais desaparecidos e encontrados acontece frequentemente por meio de redes sociais e grupos de mensagens, dificultando a centralização das informações e a colaboração entre cidadãos e organizações de proteção animal.

## Objetivo da solução

Desenvolver a proposta de uma plataforma digital colaborativa que facilite a divulgação de ocorrências, a localização de animais e a conexão entre pessoas e organizações que desejam ajudar.

## Público-alvo

- Tutores de animais;
- Cidadãos e voluntários;
- ONGs de proteção animal;
- Protetores independentes;
- Pessoas interessadas em doações.

## Funcionalidades propostas

- Cadastro de usuários;
- Registro de animais desaparecidos;
- Registro de animais encontrados;
- Pesquisa por localização;
- Cadastro de ONGs;
- Divulgação de campanhas;
- Registro de ofertas de doações e voluntariado;
- Painel de indicadores.

## Tecnologias e conceitos

- Java;
- Programação Orientada a Objetos (POO);
- Java Web;
- Arquitetura MVC;
- Padrão DAO;
- Padrão Singleton;
- Modelagem UML.

## Objetivos de Desenvolvimento Sustentável

- ODS 3 - Saúde e bem-estar

Este repositório reúne a documentação técnica, a modelagem UML, os conceitos de orientação a objetos e exemplos de código Java utilizados para demonstrar a arquitetura proposta para o PetAlerta.
